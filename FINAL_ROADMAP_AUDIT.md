## Cross-phase architecture

One shared engineering model, stable IDs, source-linked claims and SQLite repository remain. Schema 6 extends existing migrations with sync metadata and agent audit. FTS remains the sole search index. Graph is a transient view, not another database. RAG retains review/status gates and citation-ID validation. Phase 6 remains the only research-ingestion/review path. Engineering logic and model explanation are separate. Agent runs call bounded local tools and write audit only; research mode creates a brief without external access.

Sync is isolated to an explicitly permitted personal/public vault. Compare-and-swap and reviewed whole-snapshot replacement prevent silent cloud conflicts; local transactional rollback and recovery are tested. Original Mac work data remains local. Snapshot application recreates SQL claim creation/modification timestamps because the original value model omits them. IDs, claim content, source links, states and research import timestamps survive, but this timestamp loss is a metadata/provenance defect requiring a reviewed correction. No correction was made during this audit.
